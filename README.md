# Дубли - расширение Chrome под тикеты Redmine

Показывает одинаковые вкладки и одинаковые закладки в одном окне и даёт убрать
лишние. Одним тикетом считает `/issues/12345` с любым хвостом: `#note-7`,
`?tab=history`, `utm_*`.

## Установка (Chrome на маке)

1. Скопировать папку `dubli-tabs` куда-нибудь к себе, например в «Документы».
   Из папки загрузок Chrome её тоже возьмёт, но папку лучше не двигать потом:
   Chrome помнит путь, а не копирует файлы.
2. Открыть `chrome://extensions`
3. Вверху справа включить «Режим разработчика»
4. Кнопка «Загрузить распакованное расширение» → выбрать папку `dubli-tabs`
5. Иконку закрепить на панели (значок пазла → булавка)

Chrome при каждом старте покажет плашку «Отключить расширения в режиме
разработчика». Её можно закрывать крестиком, расширение продолжит работать.
Это плата за установку мимо магазина.

## Как пользоваться

**Значок.** Тёмное число на иконке - сколько вкладок лишние прямо сейчас.
Пусто - дублей нет. Считается при каждом событии со вкладками, при пробуждении
фонового процесса и раз в минуту по будильнику: Chrome в третьем манифесте
усыпляет фон через полминуты, и без будильника после перезапуска браузера
значок оставался пустым, пока не тронешь вкладку.

**Вкладки.** Клик по иконке. Группы дублей, в каждой первая помечена
«оставляем». «Оставить одну» - закрывает остальные в группе. «Схлопнуть все» -
по всем группам разом. Кого оставляем: закреплённую, если она есть, иначе
активную, иначе первую. Закреплённую вкладку расширение не закрывает никогда -
ни кнопкой группы, ни «схлопнуть все», у неё и крестика нет. Клик по названию - перейти к этой вкладке, крестик -
закрыть только её. Закрытую вкладку Chrome возвращает по Cmd+Shift+T.

**Закладки.** Выбрать папку, «Найти». Поиск идёт и по вложенным папкам.
Оставляем ту копию, что лежит выше по дереву, при равной глубине - заведённую
раньше. Лишние не удаляются: кнопка переносит их
в подпапку «Дубли ГГГГ-ММ-ДД» внутри той же папки. Удалить оттуда - руками,
когда посмотрите. Так сделано намеренно: удалённую закладку Chrome не
возвращает. При следующем поиске папки «Дубли …» пропускаются, иначе
перенесённое находилось бы снова.

**Сложить вкладки в папку.** В разделе закладок: выбрать папку и нажать
«Сложить вкладки сюда и закрыть». Берёт открытые тикеты, выкидывает дубли,
пропускает то, что в папке уже есть, сохраняет остальное и закрывает вкладки.
Закреплённые не трогает; если из окна уходят все вкладки, оставляет пустую,
иначе Chrome закрыл бы окно. Галочкой в настройках можно брать не только
тикеты, а все вкладки.

**Горячая клавиша.** Alt+Shift+D - схлопнуть дубли, не открывая окна. Поменять
можно на `chrome://extensions/shortcuts`, туда ведёт кнопка в настройках.

**Не открывать дважды** (выключено по умолчанию). Клик по тикету, который уже
открыт, переводит на ту вкладку вместо новой. Закрывается всегда более молодая:
вкладку, которую вы держите давно, увести из-под руки нельзя.

**Предупреждение о закладке.** Сохранили закладку на тикет, который уже лежит в
закладках - Chrome покажет уведомление, где именно лежит первая. Когда вкладки
складывает сама кнопка выше, уведомления молчат.

**Настройки** (шестерёнка):

- тикеты по номеру - главное правило, включено
- игнорировать `#якорь` и `www.`
- список параметров, которые не считаются различием
- подсветка на странице: помечает в списке тикетов ссылки, которые уже открыты
  во вкладке. Нужно вписать хост Redmine и нажать «Выдать доступ к хосту» -
  Chrome спросит разрешение. Без этого расширение на страницы не заходит
- не давать открыть второй раз, предупреждать о повторной закладке, брать в
  «сложить» только тикеты

## Что внутри

- `lib.js` - правило «что считать одним адресом». Одно на всё расширение
- `background.js` - счётчик на значке, ответы для подсветки
- `popup.js` / `popup.html` / `popup.css` - окно
- `mark.js` - пометки на странице, включаются в настройках

Наружу ничего не уходит: ни сети, ни аналитики, ни сторонних библиотек.
Настройки лежат в синхронизации Chrome (`chrome.storage.sync`).

## Если что-то не так

`chrome://extensions` → у расширения «Ошибки» и «Служебный воркер» - там видно
и сбой, и лог. Правки в файлах подхватываются кнопкой обновления (круговая
стрелка) на карточке расширения.
