# Прогоны расширения

Гоняются в настоящем Chromium с загруженным расширением, а не мокают Chrome API:
дефекты, которые здесь ловились, все до одного были в стыках - порядок событий,
приоритет вкладок, повторный обход дерева закладок. На заглушках их не видно.

    node tests/lib-keys.mjs                # 27 проверок: правило дубля, без браузера
    ~/.local/bin/pw tests/ext-full.mjs     # 16 проверок: вкладки и закладки
    ~/.local/bin/pw tests/ext-v11.mjs      # 12 проверок: перехват, клавиша, «сложить»
    ~/.local/bin/pw tests/ext-badge.mjs    # 6 проверок: число на значке
    ~/.local/bin/pw tests/ext-mark.mjs     # подсветка ссылок на странице
    ~/.local/bin/pw tests/ext-slozhit.mjs  # «сложить», когда вкладка закрылась на ходу
    ~/.local/bin/pw tests/ext-test.mjs     # короткий дымовой прогон

Расширение берётся из самого репозитория, playwright - из его `node_modules`
(версия закреплена в package.json). Другое место - переменными `EXT=` и
`PLAYWRIGHT=`, см. `tests/окружение.mjs`.

`ext-mark.mjs` работает с копией в `/tmp/dubli-mark-*`, где в манифест дописано
`host_permissions`. В настоящей установке это разрешение выдаёт Антон кнопкой
в настройках, а из headless-браузера окно разрешений не нажать.

Чего прогоны НЕ покрывают:

- само нажатие Alt+Shift+D. Проверяется только регистрация команды в Chrome:
  нажатия в браузерный хром из Playwright не отправить
- вкладка, пойманная в момент загрузки (`pendingUrl`), - в значке, перехвате
  и «сложить». Гонку не воспроизвести честно, правило проверено разбором кода
